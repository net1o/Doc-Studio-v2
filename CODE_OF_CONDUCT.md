# Code of Conduct

## Our Pledge

Contributors and maintainers of Document Studio commit to fostering an open, respectful, and harassment-free collaboration environment for everyone regardless of background, identity, or experience level.

## Expected Behavior

- Communicate clearly, constructively, and empathetically in issues, reviews, and discussions.
- Focus feedback on code quality, security, accessibility, and user outcomes.
- Respect project boundaries, privacy, and responsible disclosure practices.

## Unacceptable Behavior

- Harassment, personal attacks, derogatory comments, or unwelcome attention.
- Publishing private information, secrets, or sensitive user document contents.
- Bypassing review gates or introducing unauthorized production changes.
